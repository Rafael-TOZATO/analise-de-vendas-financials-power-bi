# Desafio de Projeto: Análise de Vendas com Power BI (Financials)

Repositório desenvolvido como parte do desafio prático de Power BI da plataforma **DIO**, com foco na criação de relatórios gerenciais e interativos.

---

## 📋 Sobre o Projeto
Este relatório foi estruturado utilizando a base de dados *financials sample* do Power BI, aplicando boas práticas de modelagem, design de painéis e interatividade para suporte à tomada de decisão.

---

## 🚀 Funcionalidades e Estrutura
O projeto está dividido em páginas com os seguintes recursos implementados:
- **Página 1 (Visão Geral):** 
  - Layout estruturado com identidade visual corporativa.
  - Gráficos e visuais de desempenho de vendas, lucro e unidades comercializadas.
  - Segmentadores de dados (*Slicers*) dinâmicos e botões com imagens associadas.
- **Página 2 (Análise Detalhada):**
  - Utilização de indicadores (*Bookmarks*) para alternância dinâmica entre diferentes visuais sobre o mesmo assunto.
  - Botões de navegação avançada para garantir uma experiência fluida de relatório interativo.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Microsoft Power BI Desktop:** Ferramenta principal para tratamento, modelagem e construção dos visuais.
- **Git & GitHub:** Versionamento e hospedagem do código-fonte e documentação do projeto.
