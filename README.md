# Desafio de Projeto: Análise de Vendas com Power BI (Financials)

> **AI Engineer | Especialista em Governança 4.0 e Qualidade | Engenheiro Químico**  
> [Mauá, SP](mailto:ornelas.tozato@gmail.com) | [LinkedIn](https://www.linkedin.com/in/rafaeltozato81) | [GitHub](https://github.com/Rafael-TOZATO) | [Portfólio PWA](https://tozato-dev-hub.vercel.app) | [Medium](https://medium.com/@ornelas.tozato)

Repositório desenvolvido como parte do desafio prático de Power BI da plataforma **DIO**, com foco na criação de relatórios gerenciais e interativos.

## 📌 Sobre o Projeto

Este relatório foi estruturado utilizando a base de dados *financials sample* do Power BI, aplicando boas práticas de modelagem, design de painéis e interatividade para suporte à tomada de decisão.

## 🚀 Funcionalidades e Estrutura

O projeto está dividido em páginas com os seguintes recursos implementados:
- **Página 1 (Visão Geral):**
  - Layout estruturado com identidade visual corporativa.
  - Gráficos e visuais de desempenho de vendas, lucro e unidades comercializadas.
  - Segmentadores de dados (*slicers*) dinâmicos e botões com imagens associadas.

- **Página 2 (Análise Detalhada):**
  - Utilização de indicadores (*Bookmarks*) para alternância dinâmica entre diferentes visuais sobre o mesmo assunto.
  - Botões de navegação avançada para garantir uma experiência fluida de relatório interativo.

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Microsoft Power BI Desktop:** ferramenta principal para tratamento, modelagem e construção dos visuais.
- **Git & GitHub:** versionamento e hospedagem do código-fonte e documentação do projeto.

## 📁 Como Acessar o Relatório

Para visualizar o projeto completo, realize o download do arquivo presente neste repositório:
- **Arquivo:** [Desafio_Power_BI_Analyst_DIO.pbix](./Desafio_Power_BI_Analyst_DIO.pbix)

Após o download, abra o arquivo utilizando o software **Power BI Desktop**.

## 🛡️ Governança 4.0 — Segurança e Qualidade

Este repositório adota controles automatizados de Governança 4.0 para assegurar integridade dos artefatos e do código, rastreabilidade das alterações, gestão de dependências e prevenção de exposição de credenciais.

* **Automação de Qualidade e Segurança:** Análises automatizadas e portas de verificação (*status checks*) ativas em segundo plano.
* **Fluxo Sem Atrito:** Dispensa de aprovações manuais redundantes com *auto-merge* habilitado para agilizar entregas.
* **Integridade de Código:** Proteção de branch e bloqueio de *force pushes* para garantir a estabilidade da base principal.
